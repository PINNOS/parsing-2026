# Лабораторная работа №6. Хранение, очистка и структурирование собранных данных

Вариант 1: Товарный каталог (объединение ≥2 источников разной природы).

## Цель
Построить трёхслойное хранилище (raw → clean → mart) с очисткой, контрактом данных, идемпотентной загрузкой в БД, историей изменений, метриками качества и сопоставлением с no-code.

## Источники
- 3lab (REST API): `3lab/data_raw.jsonl` — товары с API.
- 5lab (Scrapy): `5lab/lab5_6/data/items.jsonl` — товары со страниц/краулинга.

Оба приведены к общему формату в `raw/` с метаданными `_source`, `_source_url`, `_collected_at`, `_parser_version`, `_status`.

## Структура
- `raw/` — JSONL, только дозапись
- `clean/` — Parquet + `rejects.jsonl` + `format_benchmark.csv`
- `mart/` — аналитические представления и партиционированные снапшоты
- `db/` — `schema.sql`, `warehouse.db`, `load.py`
- `src/` — `rebuild.py`, `clean.py`, `contract.py`, `quality.py`
- `6lab.ipynb` — полная программная часть
- `nocode/` — `workflow.json`, скриншоты, `nocode_result.csv`
- `report.md` — отчёт

## Воспроизведение
1. Установить зависимости: `pip install -r requirements.txt`
2. Открыть и запустить `6lab.ipynb` (ячейки по порядку)
3. Запустить no-code часть по инструкции в отчёте.
